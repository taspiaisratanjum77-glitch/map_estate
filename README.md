# 🏠 Commute-Home (Map Estate)

An interactive real estate map application built with HTML, CSS, and JavaScript. It helps users discover rental and residential properties across Dhaka (such as Banani, Gulshan, Mohakhali) and calculate commute times and distances between workplace locations and prospective homes.

---

## ✨ Features

- 🗺️ **Interactive Leaflet Map**: Explore listings with custom markers, popups, and ArcGIS street map tiles.
- 🚗 **Commute Calculator**: Enter your workplace address/coordinates to calculate commute distance and travel duration via OpenRouteService (ORS).
- 🔍 **Area Filtering**: Filter properties easily by location (Banani, Gulshan, Mohakhali, etc.).
- 🖼️ **Property Details Modal**: View comprehensive specifications including rent, room count, floor details, amenities, and image gallery.
- ⚡ **Zero Build Tools Required**: Pure client-side web application running directly in any modern web browser.

---

## 🛠️ Tech Stack

- **HTML5** & **CSS3** (Responsive design, modal overlays, flexbox/grid layout)
- **JavaScript (ES6+)** (DOM manipulation, async API requests)
- **Leaflet.js** (Interactive mapping library)
- **OpenRouteService (ORS) API** (Route calculations and commute estimation)
